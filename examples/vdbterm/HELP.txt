1. INTRODUCTION
===============================================================================

VDBTerm is a Visual DBasic Terminal IDE - a modern clone of VBDos Pro for
terminal environments. It allows you to create visual forms with drag-and-drop
control placement, edit properties, write code, and manage projects entirely
within a terminal interface.

2. KEYBOARD SHORTCUTS
===============================================================================

Global Shortcuts:
    F1          Help dialog
    F5          Run project (generates code)
    F7          Toggle between Form and Code view
    F10         Open File menu

    Alt+V       View menu
    Alt+R       Run menu

    Arrow Keys  Move selected control

    Enter       Add selected control type to form

    Arrow Keys  Move cursor
    Home        Go to beginning of line
    End         Go to end of line
    Page Up     Scroll up
    Page Down   Scroll down
    Backspace   Delete character before cursor
    Delete      Delete character at cursor

4. RESERVED SYSTEM VARIABLES
===============================================================================

Reserved system variables are prefixed with $ and can be used in control
property expressions. They provide dynamic values based on the current
terminal and form state.

Screen/Window Variables:
------------------------
    $SCREEN_WIDTH       Current terminal width in characters
    $SCREEN_HEIGHT      Current terminal height in characters
    $FORM_WIDTH         Current form design width
    $FORM_HEIGHT        Current form design height
    $CONTENT_WIDTH      Width of the form canvas area (screen minus panels)
    $CONTENT_HEIGHT     Height of the form canvas area (screen minus bars)

Layout Constants:
-----------------
    $TOOLBOX_WIDTH      Width of the toolbox panel (16 characters)
    $PROPERTIES_WIDTH   Width of the properties panel (22 characters)
    $PROJECT_HEIGHT     Height of the project tree panel (8 rows)

Example Usage in Control Properties:
------------------------------------
    XExpr = "$CONTENT_WIDTH - 20"
        Positions control 20 characters from the right edge

    WidthExpr = "$CONTENT_WIDTH / 2"
        Makes control half the width of the content area

    YExpr = "$CONTENT_HEIGHT - 5"
        Positions control 5 rows from the bottom

    XExpr = "($FORM_WIDTH - 10) / 2"
        Centers a 10-character wide control horizontally

5. EXPRESSION SYNTAX
===============================================================================

Expressions support basic arithmetic operations and can include reserved
system variables. The expression evaluator processes these when rendering.

Supported Operators:
    +       Addition
    -       Subtraction
    *       Multiplication
    /       Division (integer division)

Parentheses:
    ( )     Group operations for precedence

Operator Precedence:
    1. Parentheses (highest)
    2. Multiplication and Division
    3. Addition and Subtraction (lowest)

Examples:
    "10"                    Literal value 10
    "$SCREEN_WIDTH"         Current screen width
    "$SCREEN_WIDTH - 20"    Screen width minus 20
    "100 / 2"               Evaluates to 50
    "(10 + 5) * 2"          Evaluates to 30
    "$CONTENT_WIDTH / 2 - 5"   Half content width minus 5

6. CONTROL TYPES
===============================================================================

VDBTerm supports the following control types:

    Button      [Btn]   Command button for user actions
    Label        Lbl    Static text display
    TextBox     [___]   Single-line text input field
    CheckBox    [X]     Boolean toggle (checked/unchecked)
    Option      (o)     Radio button (one of a group)
    ListBox     [=]     Scrollable list of items
    ComboBox    [v]     Dropdown list with text entry
    Frame       [-]     Container for grouping controls
    HScrollBar  <=>     Horizontal scroll bar
    VScrollBar  [|]     Vertical scroll bar
    Timer        T      Non-visual timer control

Control Properties (common):
    Name        Unique identifier for the control
    Caption     Display text (buttons, labels, checkboxes, etc.)
    X           Horizontal position on form
    Y           Vertical position on form
    Width       Width in characters
    Height      Height in rows
    Enabled     Whether control responds to input
    Visible     Whether control is displayed
    Value       Current value (textboxes, checkboxes, etc.)

7. PROPERTIES PANEL
===============================================================================

The Properties panel (right side) displays properties of the currently
selected control or the form itself.

When a control is selected:
    Name        Control's name (used in code)
    Type        Control type (read-only)
    Caption     Display text
    X           X position
    Y           Y position
    Width       Control width
    Height      Control height
    Enabled     True/False
    Visible     True/False

When no control is selected (form properties):
    Name        Form name
    Caption     Form title
    Width       Form design width
    Height      Form design height

===============================================================================
8. CODE EDITOR
===============================================================================

Press F7 to toggle between Form view and Code view.

The Code Editor provides a simple text editing environment for writing
DBasic code associated with each form.

Default Form Code Structure:
    ' Form1 Code

    SUB Form_Load()
        ' Initialization code here
    END SUB

Event Procedures:
    Form_Load       Called when form is loaded
    Button_Click    Called when button is clicked
    TextBox_Change  Called when text changes

===============================================================================
9. PROJECT STRUCTURE
===============================================================================

A VDBTerm project consists of:

    Project
    +-- Forms (visual forms with controls)
    |   +-- Form1.frm
    |   +-- Form2.frm
    |   +-- ...
    +-- Modules (code-only files)
        +-- Module1.bas
        +-- ...

The Project Tree (bottom panel) shows this structure. Click on items to
switch between forms and modules.

Project Operations (File menu):
    New Project     Create a new empty project
    Open Project    Load an existing project file
    Save Project    Save current project to file
    New Form        Add a new form to the project
    New Module      Add a new code module to the project
