1. FORM
================================================================================

The Form is the main container for all controls.

PROPERTIES:
---------------------------------------------------------------------------
  Property      Type      Description
---------------------------------------------------------------------------
  Name          STRING    Form identifier (e.g., "frmMain")
  Caption       STRING    Window title displayed in border
  X, Y          INTEGER   Position on screen
  Width         INTEGER   Form width (includes border)
  Height        INTEGER   Form height (includes border)
  BackColor     INTEGER   Background color code

EVENTS:
---------------------------------------------------------------------------
  Event         Description
---------------------------------------------------------------------------
  Load          Fired when form loads (use for initialization)
  Unload        Fired when form closes
  Activate      Fired when form gains focus
  Deactivate    Fired when form loses focus
  Resize        Fired when form is resized
  KeyPress      Fired on key press

EXAMPLE:
---------------------------------------------------------------------------
  SUB Form_Load()
      lblWelcome.Caption = "Welcome to my application!"
      lstItems.AddItem("First Item")
  END SUB

================================================================================
2. BUTTON
================================================================================

A clickable button control.

PROPERTIES:
---------------------------------------------------------------------------
  Property      Type      Description
---------------------------------------------------------------------------
  Name          STRING    Control identifier (e.g., "btnOK")
  Caption       STRING    Button text
  X, Y          INTEGER   Position relative to form interior
  Width         INTEGER   Button width in characters
  Height        INTEGER   Button height (1 for flat, 3+ for bordered)
  Enabled       BOOLEAN   TRUE = enabled, FALSE = disabled
  Visible       BOOLEAN   TRUE = visible, FALSE = hidden
  TabIndex      INTEGER   Tab order position
  Border        BOOLEAN   TRUE = 3-row bordered style, FALSE = flat
  ForeColor     INTEGER   Text color
  BackColor     INTEGER   Background color

EVENTS:
---------------------------------------------------------------------------
  Event         Description
---------------------------------------------------------------------------
  Click         Fired when button is clicked or Enter pressed
  MouseDown     Fired on mouse button down
  MouseUp       Fired on mouse button up
  GotFocus      Fired when button receives focus
  LostFocus     Fired when button loses focus

EXAMPLE:
---------------------------------------------------------------------------
  SUB btnOK_Click()
      lblStatus.Caption = "OK was clicked!"
  END SUB

4. TEXTBOX
================================================================================

A single-line text input control.

PROPERTIES:
---------------------------------------------------------------------------
  Property      Type      Description
---------------------------------------------------------------------------
  Name          STRING    Control identifier (e.g., "txtName")
  X, Y          INTEGER   Position relative to form interior
  Width         INTEGER   TextBox width in characters
  Height        INTEGER   TextBox height (usually 1)
  Enabled       BOOLEAN   TRUE = enabled, FALSE = disabled
  Visible       BOOLEAN   TRUE = visible, FALSE = hidden
  TabIndex      INTEGER   Tab order position
  Value/Text    STRING    Text content
  Placeholder   STRING    Hint text shown when empty
  CharLimit     INTEGER   Maximum characters (0 = unlimited)
  EchoMode      INTEGER   0 = Normal, 1 = Password, 2 = None
  Prompt        STRING    Prefix text displayed before input
  CursorBlink   BOOLEAN   TRUE = cursor blinks
  ForeColor     INTEGER   Text color
  BackColor     INTEGER   Background color

EVENTS:
---------------------------------------------------------------------------
  Event         Description
---------------------------------------------------------------------------
  Change        Fired when text changes
  KeyPress      Fired on each key press
  GotFocus      Fired when TextBox receives focus
  LostFocus     Fired when TextBox loses focus
  Validate      Fired before losing focus (for validation)

FUNCTIONS:
---------------------------------------------------------------------------
  txtName.Value = "text"       ' Set text content
  txtName.Text = "text"        ' Set text content (alias)
  text = txtName.Value         ' Get text content
  text = txtName.Text          ' Get text content (alias)
  txtName.Focus()              ' Set focus to this control
  txtName.Blur()               ' Remove focus from this control

EXAMPLE:
---------------------------------------------------------------------------
  SUB btnSubmit_Click()
      IF txtName.Text = "" THEN
          lblError.Caption = "Please enter your name"
      ELSE
          lblGreeting.Caption = "Hello, " & txtName.Text & "!"
      ENDIF
  END SUB

---------------------------------------------------------------------------
  Property      Type      Description
---------------------------------------------------------------------------
  Name          STRING    Control identifier (e.g., "chkActive")
  Caption       STRING    Label text next to checkbox
  X, Y          INTEGER   Position relative to form interior
  Width         INTEGER   Control width in characters

  Enabled       BOOLEAN   TRUE = enabled, FALSE = disabled
  Visible       BOOLEAN   TRUE = visible, FALSE = hidden
  TabIndex      INTEGER   Tab order position
  Value/Checked BOOLEAN   TRUE = checked, FALSE = unchecked
  ForeColor     INTEGER   Text color
  BackColor     INTEGER   Background color

EVENTS:
---------------------------------------------------------------------------
  Event         Description
---------------------------------------------------------------------------
  Click         Fired when checkbox is clicked/toggled
  Change        Fired when checked state changes
  GotFocus      Fired when checkbox receives focus
  LostFocus     Fired when checkbox loses focus

FUNCTIONS:
---------------------------------------------------------------------------
  chkName.Checked = TRUE       ' Set checked state
  chkName.Value = TRUE         ' Set checked state (alias)
  state = chkName.Checked      ' Get checked state
  state = chkName.Value        ' Get checked state (alias)

EXAMPLE:
---------------------------------------------------------------------------
  SUB chkNotify_Click()
      IF chkNotify.Checked THEN
          lblStatus.Caption = "Notifications enabled"
      ELSE
          lblStatus.Caption = "Notifications disabled"
      ENDIF
  END SUB

6. OPTION (Radio Button)
================================================================================

A radio button for mutually exclusive selections within a group.

PROPERTIES:
---------------------------------------------------------------------------
  Property      Type      Description
---------------------------------------------------------------------------
  Name          STRING    Control identifier (e.g., "optMale")
  Caption       STRING    Label text next to radio button
  X, Y          INTEGER   Position relative to form interior
  Width         INTEGER   Control width in characters
  Height        INTEGER   Control height (usually 1)
  Enabled       BOOLEAN   TRUE = enabled, FALSE = disabled
  Visible       BOOLEAN   TRUE = visible, FALSE = hidden
  TabIndex      INTEGER   Tab order position
  Value/Selected BOOLEAN  TRUE = selected, FALSE = not selected
  GroupName     STRING    Name to group radio buttons together
  ForeColor     INTEGER   Text color
  BackColor     INTEGER   Background color

EVENTS:
---------------------------------------------------------------------------
  Event         Description
---------------------------------------------------------------------------
  Click         Fired when option is clicked/selected
  Change        Fired when selected state changes
  GotFocus      Fired when option receives focus
  LostFocus     Fired when option loses focus

FUNCTIONS:
---------------------------------------------------------------------------
  optName.Selected = TRUE      ' Select this option (deselects others)
  optName.Value = TRUE         ' Select this option (alias)
  state = optName.Selected     ' Get selected state
  state = optName.Value        ' Get selected state (alias)

NOTE: When an option is selected, all other options in the same group
      are automatically deselected.

EXAMPLE:
---------------------------------------------------------------------------
  SUB optSmall_Click()
      lblSize.Caption = "Size: Small"
  END SUB

  SUB optMedium_Click()
      lblSize.Caption = "Size: Medium"
  END SUB

  SUB optLarge_Click()
      lblSize.Caption = "Size: Large"
  END SUB

7. LISTBOX
================================================================================

A scrollable list of selectable items.

PROPERTIES:
---------------------------------------------------------------------------
  Property          Type      Description
---------------------------------------------------------------------------
  Name              STRING    Control identifier (e.g., "lstItems")
  X, Y              INTEGER   Position relative to form interior
  Width             INTEGER   ListBox width in characters
  Height            INTEGER   ListBox height in rows
  Enabled           BOOLEAN   TRUE = enabled, FALSE = disabled
  Visible           BOOLEAN   TRUE = visible, FALSE = hidden
  TabIndex          INTEGER   Tab order position
  Items             STRING    Semicolon-separated initial items
  Title             STRING    Title text (if ShowTitle = TRUE)
  ShowTitle         BOOLEAN   TRUE = show title bar
  ShowStatusBar     BOOLEAN   TRUE = show status bar
  ShowFilter        BOOLEAN   TRUE = enable type-to-filter
  InfiniteScrolling BOOLEAN   TRUE = wrap at list ends
  ForeColor         INTEGER   Text color
  BackColor         INTEGER   Background color

EVENTS:
---------------------------------------------------------------------------
  Event         Description
---------------------------------------------------------------------------
  Click         Fired when item is selected
  DblClick      Fired on double-click
  Change        Fired when selection changes
  GotFocus      Fired when ListBox receives focus
  LostFocus     Fired when ListBox loses focus

FUNCTIONS:
---------------------------------------------------------------------------
  lstName.AddItem("text")      ' Add item to end of list
  idx = lstName.SelectedIndex  ' Get selected item index (0-based, -1 if none)
  item = lstName.SelectedItem  ' Get selected item text
  lstName.SelectedIndex = 0    ' Select item by index
  lstName.SelectedIndex = -1   ' Clear selection

EXAMPLE:
---------------------------------------------------------------------------
  SUB Form_Load()
      lstFruits.AddItem("Apple")
      lstFruits.AddItem("Banana")
      lstFruits.AddItem("Cherry")
      lstFruits.SelectedIndex = 0
  END SUB

  SUB lstFruits_Click()
      lblSelected.Caption = "You selected: " & lstFruits.SelectedItem
  END SUB

13. PROGRESS
================================================================================

A progress bar to display completion status.

PROPERTIES:
---------------------------------------------------------------------------
  Property       Type      Description
---------------------------------------------------------------------------
  Name           STRING    Control identifier (e.g., "prgStatus")
  X, Y           INTEGER   Position relative to form interior
  Width          INTEGER   Progress bar width in characters
  Height         INTEGER   Progress bar height (usually 1)
  Enabled        BOOLEAN   TRUE = enabled, FALSE = disabled
  Visible        BOOLEAN   TRUE = visible, FALSE = hidden
  Value          INTEGER   Current progress value
  Total          INTEGER   Maximum value (default 100)
  ShowPercentage BOOLEAN   TRUE = show percentage text
  ForeColor      INTEGER   Bar color
  BackColor      INTEGER   Background color

EVENTS:
---------------------------------------------------------------------------
  Event         Description
---------------------------------------------------------------------------
  Change        Fired when value changes
  Complete      Fired when Value reaches Total

FUNCTIONS:
---------------------------------------------------------------------------
  prgName.Value = 50           ' Set progress value
  prgName.Total = 100          ' Set total/maximum value
  val = prgName.Value          ' Get current value

EXAMPLE:
---------------------------------------------------------------------------
  SUB tmrProgress_Timer()
      prgDownload.Value = prgDownload.Value + 5
      IF prgDownload.Value >= prgDownload.Total THEN
          tmrProgress.Enabled = FALSE
          lblStatus.Caption = "Download complete!"
      ENDIF
  END SUB

14. SPINNER
================================================================================

An animated spinner to indicate activity.

PROPERTIES:
---------------------------------------------------------------------------
  Property      Type      Description
---------------------------------------------------------------------------
  Name          STRING    Control identifier (e.g., "spnLoading")
  X, Y          INTEGER   Position relative to form interior
  Width         INTEGER   Spinner width (usually 1-3)

EVENTS:
---------------------------------------------------------------------------
  Event         Description

---------------------------------------------------------------------------

  spnName.Visible = FALSE      ' Hide and stop spinner
  spnName.Style = 1            ' Set animation style

EXAMPLE:
---------------------------------------------------------------------------
  SUB btnProcess_Click()
      spnWorking.Visible = TRUE
      ' ... do processing ...
      spnWorking.Visible = FALSE
  END SUB

16. TIMER (Non-Visible)
================================================================================

A timer control that fires events at regular intervals.
This control appears in the Toolbox panel (non-visible at runtime).

PROPERTIES:
---------------------------------------------------------------------------
  Property      Type      Description
---------------------------------------------------------------------------
  Name          STRING    Control identifier (e.g., "tmrUpdate")
  Enabled       BOOLEAN   TRUE = running, FALSE = stopped
  Interval      INTEGER   Milliseconds between Timer events

EVENTS:
---------------------------------------------------------------------------
  Event         Description
---------------------------------------------------------------------------
  Timer         Fired each time the interval elapses

FUNCTIONS:
---------------------------------------------------------------------------
  tmrName.Enabled = TRUE       ' Start the timer
  tmrName.Enabled = FALSE      ' Stop the timer

NOTE: The Interval property can only be set at design time.

EXAMPLE:
---------------------------------------------------------------------------
  DIM counter AS INTEGER

  SUB Form_Load()
      counter = 0
      tmrClock.Enabled = TRUE     ' Start with 1000ms interval
  END SUB

  SUB tmrClock_Timer()
      counter = counter + 1
      lblTime.Caption = "Seconds: " & Str(counter)
  END SUB

  SUB btnStop_Click()
      tmrClock.Enabled = FALSE
  END SUB

20. GLOBAL HELPER FUNCTIONS
================================================================================

These functions are automatically generated and available in your code:

FOCUS MANAGEMENT:
---------------------------------------------------------------------------
  CycleFocus(m, direction)
      Move focus to next (direction=1) or previous (direction=-1) control

  ClearFocus(m)
      Remove focus from all controls

  SetFocus(m, controlName)
      Set focus to the named control

  SetFocusIndex(m, controlName)
      Update internal focus index to match the named control

  GetFocusCmd(m)
      Get the appropriate cursor blink command for the focused control

LISTBOX HELPERS:
---------------------------------------------------------------------------
  AddListItem(lst, text)
      Add an item to a list, returns the updated list model

  GetSelectedListItem(lst)
      Get the text of the currently selected item

  SetListIndex(lst, idx)
      Set the selection to the specified index

RADIO BUTTON GROUPS:
---------------------------------------------------------------------------
  SelectOption(m, optionName)
      Select the named option and deselect all others in its group
